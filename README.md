# Tudo-Busca — Buscador de Cupons e Notebooks Dell

Página HTML única e offline com cupons de desconto e notebooks Dell de várias lojas (Dell.com, KaBuM!, Amazon, iByte/WAZ/Webcontinental, Zoom/Buscapé), com filtros e nota de custo-benefício.

- `cupons-dell.html` — página final com os dados embutidos. Basta abrir no navegador.
- `logica-cupons-dell.md` — documentação completa: pipeline de coleta, esquema dos dados, interface e cálculo da nota.

Os scripts de coleta (`dell-scraper/`) ainda não estão neste repositório.
